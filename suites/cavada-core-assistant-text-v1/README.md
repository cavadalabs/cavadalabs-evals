# Cavada Core Assistant Text v1

Status: `draft`; assurance: `development`.

This is the first planned high-assurance CavadaLabs suite. It evaluates a fixed
general-purpose conversational assistant configuration in English and Italian.
It does not cover RAG, tools, MCP, code execution, images, audio, video, or
professional fitness in high-impact domains.

The four current dataset rows are authoring fixtures only. They test the schema
and deterministic authoring path; they are not a benchmark sample, calibration
set, holdout, or evidence of model quality. The frozen design target is 1,840
independent cases, subject to pre-pilot statistical review.

Read `MEASUREMENT_SPEC.md`, `STATISTICAL_ANALYSIS_PLAN.md`, and
`case_blueprint.toml` before authoring cases. Do not create the private holdout
in this public repository.
