# Roadmap

## Now

- Make the offline demo and first contribution take minutes, not hours.
- Calibrate and independently approve the first official CavadaLabs suite.
- Publish reproducible example bundles without private or customer data.

## Next

- Add more OpenAI-compatible engine contract fixtures and comparison examples.
- Expand synthetic multimodal and agent evaluation examples with explicit limits.
- Improve report accessibility and public result communication.

## Later

- Add optional external benchmark adapters only where licensing permits.
- Add optional experiment tracking without making historical bundles depend on it.
- Consider a stable 1.0 protocol after real independent use and review.

This roadmap is directional, not a promise. Security, integrity, and review
gates take priority over feature count.
